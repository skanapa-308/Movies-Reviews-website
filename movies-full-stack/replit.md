# My App

## Overview
A simple HTML/CSS/JS web application with an interactive click counter.

## Project Structure
- `index.html` - Main HTML page
- `styles.css` - Styling with gradient backgrounds and modern design
- `script.js` - JavaScript for click counter interactivity
- `server.py` - Simple Python HTTP server on port 5000

## Running the App
The app runs via a Python HTTP server on port 5000.
